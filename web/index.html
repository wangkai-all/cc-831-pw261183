工作包不可拆分；成员用自己的估时承担负荷，用自己的眼睛评估嫉妒。 求解器只在资格、容量、同包/互斥和已接受承诺都满足时给方案，不靠改估时制造可行解。

接受台账 / 承诺锁

成员接受后，重算只允许移动未接受项。若同包依赖把未接受项强制带给同一人，卡片会标注“依赖强制”。已接受包改给他人会被拒绝；演示请清空或恢复示例台账。

小实例独立枚举核对

不经过块压缩，直接枚举所有“工作包 × 成员”组合，再用独立硬约束检查器过滤。 此核对默认不套用台账锁，专门验证资格、容量、同包/互斥与最优界；承诺锁由上方求解器和后端测试核对。

数据均为虚构。求解器使用 Python 标准库实现完整 DFS/枚举；无外部优化器、无前端图表库。 可运行 python -m unittest discover -s tests -v 核对最优界与承诺冲突。
